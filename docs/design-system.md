# Дизайн-система «Консоль»

> Единственный источник правды по виду. Токены — `src/styles/tokens.css`, иконки — `src/ui/icons.ts`,
> Палыч — `src/ui/palych-art.ts` + `src/styles/mascot.css`. Стенд для глаз: `design/preview.html`
> (`npm run dev` → `/linux-trainer/design/preview.html`, в сборку не входит).

## Направление
**Идея.** Экран выглядит как окно рабочей станции 90-х (SGI/NeXT/CDE, Plan 9): жёсткие прямоугольники,
рамки в 2px, тени-«блоки» без размытия, плотная таблица вместо карточек. Но собрано по-современному:
тёплый графит вместо чёрного, «костяной» текст, один янтарный акцент, нормальные читаемые шрифты,
пиксельный шрифт только как подпись-характер. Отсылки к ядру — в языке интерфейса: темы пронумерованы как PID,
статусы — как состояния процесса (`S` не начата, `R` в работе, `0` — завершена с exit 0), прогресс — полоска `[####....]`,
ошибка — `FAIL exit 1`, реплики Палыча — строка в окне `palych@srv ~`.
**Не делаем:** зелёный-на-чёрном, свечение/CRT-эффекты поверх текста, градиенты, скругления-таблетки, мягкие тени,
эмодзи, несколько ярких цветов одновременно. CRT — только намёк в фоне (`--scanline`, `--dither`, ≤3% яркости).
Поиск: Retro-futurism/TUI в 2026 строится на сетке символов, рамках и жёстких смещённых тенях (подтверждено
обзорами TUI-дизайна), без sans-serif «по умолчанию» — поэтому у нас Plex (IBM-наследие) + пиксельные акценты.

## Цвета (роли, не декор)
| Токен | Значение | Роль |
|---|---|---|
| `--c-bg` | #13120f | основа экрана (тёплый графит) |
| `--c-surface` / `-2` | #1b1a16 / #24221d | строки, панели / кнопки, поля, лист-шторка |
| `--c-term` | #0d0c0a | окно терминала и реплика Палыча (глубже основы) |
| `--c-line` / `--c-line-strong` | #3b3830 / #5a564a | разделители / активные рамки, тень-блок |
| `--c-text` / `-2` / `--c-muted` | #ece5d3 / #b3ac99 / #8d8775 | основной (14:1) / вторичный (8:1) / подписи (≥4.9:1) |
| `--c-accent` | #f2a03d | **единственный акцент**: главная кнопка, текущая тема, курсор, прогресс, XP |
| `--c-ok` | #8fb67e | успех (шалфей) — только текст/полоса/иконка |
| `--c-err` | #e5675b | ошибка (коралл-кирпич) |
| `--c-warn` | #d2bd7d | «ловушка»/внимание (песок), всегда пунктирная рамка + слово |
Правила: цвет никогда не единственный носитель смысла (рядом иконка или слово `OK`/`FAIL`/`ЛОВУШКА`);
на экране одновременно не больше акцента + одного семантического; заливки семантики — только `*-soft` (14%).
Текст на акценте — `--c-accent-ink`. Светлой темы нет (решение: экран на солнце читается за счёт контраста ≥ 7:1 основного текста).

## Типографика
Только `@fontsource`, подмножества latin + cyrillic (меньше бандл), веса ограничены:
- **IBM Plex Sans 400/600** — текст уроков, названия тем, интерфейс (`--f-ui`).
- **IBM Plex Mono 400/600** — команды, терминал, числа, метки, кнопки-капсом (`--f-mono`).
- **Pixelify Sans 600** — *только* логотип, крупные цифры (XP, номер урока), заголовок экрана (`--f-pixel`).
Размеры: 12 / 14 / 16 / 20 / 28; пиксельный 22. Межстрочный 1.5 для текста, 1.2 для заголовков.
Метки-капсом (`ТЕОРИЯ`, `ЛОВУШКА`): mono 11–12px, `letter-spacing: .1em`.
Старые Nunito/JetBrains Mono удаляются на этапе 2 вместе с `app.css`-переменными.

## Сетка и отступы
Шаг 4px: 4/8/12/16/24/32/48. Боковое поле 16px. Цель касания ≥ 48px (`--tap`). Основные действия — внизу, в зоне большого пальца.
Максимальная ширина контента 560px по центру (как сейчас). Радиусы 0–4px, рамка 2px (`--bw`), тонкая 1px для строк.

## Компоненты
- **Кнопка.** Mono 14/600, капсом, `letter-spacing:.06em`, высота ≥ 48. Основная: фон акцент, текст `accent-ink`,
  рамка 2px тёмная, тень-блок `--shadow-block-accent` (3px 3px 0). Нажатие: `translate(3px,3px)` + тень в 0 (120мс).
  Вторичная: `--c-surface-2`, рамка `--c-line-strong`, тень `--shadow-block`. Disabled: без тени, текст `--c-muted`.
- **Список тем (таблица процессов).** Строка 56px: `PID`(muted, mono) · название (Plex Sans) · `[####....]` · статус `S/R/T/0`.
  Текущая тема: фон `--c-accent-soft` + левая полоса 3px акцента. Раздел — заголовок-метка mono капсом с линией (`/proc/…`).
  Уровень: `user` (база) / `kernel` (mid) — метка muted. Не заблокировано, нет замков.
- **Прогресс `[####....]`.** Моно-строка символов либо CSS-сегменты (`repeating-linear-gradient`, шаг 6px) — в Plex Mono `#` рисуется
  перечёркнутым, поэтому в UI рисуем сегментами 4×14px акцентного цвета/`--c-line`. Скобки `[` `]` — текстом.
- **Плашка результата.** Левая полоса 4px + `*-soft` фон + mono: `OK exit 0 · +10 XP` / `FAIL exit 1 · <причина>`.
  Занимает низ экрана, под ней кнопка «Дальше».
- **Лист-шторка теории.** Снизу, `--c-surface-2`, верхняя рамка 2px `--c-line-strong`, шапка как заголовок окна:
  `[ ] man: chmod` + кнопка закрыть (иконка `close`), 88% высоты, открытие — сдвиг снизу 240мс.
- **Выноска «ловушка».** Пунктирная рамка 1px `--c-warn`, фон `--c-warn-soft`, метка `ЛОВУШКА` (mono капсом, `--c-warn`) + иконка `warning`.
- **Бейджи статуса.** Одна mono-буква в квадрате 20px с рамкой 1px: `S` muted, `R` accent, `T` text-2, `0` ok. Подпись-расшифровка в профиле.
- **Терминал.** Фон `--c-term`, рамка 2px, шапка-строка `user@server1` muted; приглашение `[user@server1 dir]$` в `--c-text-2`, ввод — `--c-text`, курсор — блок акцента.
- **Реплика Палыча.** Окно `--c-term`, рамка 2px, тень-блок, строка `palych@srv ~` muted + текст mono 13.5px, курсор-блок акцента мигает.

## Иконки
`icon(name, {size})` из `src/ui/icons.ts`: сетка 24, линия 2px, `square` окончания и `miter` углы (как рамки TUI), `currentColor`, без эмодзи.
Набор: program, terminal, profile, book, check, cross, lock, flame, bolt, play, back, close, chevron, hint, star, exam, known,
warning, sound-on, sound-off, export, import, trash, refresh, dot. Размеры: 16 (в строке), 20 (чип), 24 (навигация).
Навигация снизу — иконка + подпись mono 11px, активная — акцент + линия 2px над иконкой.

## Анимации
Короткие (120–360мс), только transform/opacity. Токены `--d-fast/base/slow`, `--ease`, дискретный `--ease-snap` (steps) — «кадры».
- **Успех:** плашка выезжает снизу 200мс, иконка `check` «рисуется» (stroke-dashoffset), Палыч `happy`/`proud`.
- **Ошибка:** плашка + 2 коротких сдвига ±4px (240мс), Палыч `angry`/`facepalm`.
- **Стрик:** иконка `flame` пульсирует scale 1→1.15→1 раз, цифра в Pixelify.
- **Терминал:** вывод строка за строкой шагом `steps`, курсор-блок мигает 1с.
- **Переход экрана:** fade + 8px вверх, 200мс. Нажатие кнопки — смещение на тень.
- **`prefers-reduced-motion: reduce`:** токены длительностей → 0, `mascot.css` отключает все анимации, остаются статичные позы.

## Палыч
Старый сисадмин, **персонаж, а не стикер**: пропорции человека (бюст по пояс, голова ~1/3), тёмный контур тёплым «чернилом»,
ограниченная палитра (кожа 3 тона, седой, кардиган оливково-коричневый, майка кость), полутона точечным дизерингом (отсылка к
битмапу), амбер-акценты (бейдж, отвёртка, `>_` на кружке). Детали: залысина с редкими волосинами и седыми клочками, очки
чёрной пластмассой с изолентой на переносице, мешки и морщины, нос-картошка, усы, щетина, растянутый кардиган с кожаными
заплатами на локтях, майка `RTFM` с пятном кофе, бейдж `UID 0` на поле, отвёртка и ручка в кармане, кружка `>_`, сигарета.
Цвета рисунка — переменные `--pk-*` в `mascot.css`.
**Настроения** (`Mood`): idle, happy, angry, shock, think, sleep, smug, facepalm, proud, typing, nervous, bored.
**Жизнь сама по себе:** дыхание, покачивание головы, моргание (тяжёлые веки), взгляд по сторонам, глоток кофе (рука с кружкой
поднимается), затяжка (дым, тлеющий кончик ярче), пар, шевелящиеся клочки волос, засыпание через минуту.
**API:** `new Mascot({size, bubble, greet})`, `say(text, ms)`, `setMood(mood, ms)`, `react(key, mood?, say?)`, `poke()`,
`sip()`, `puff()`, `armSlow(ms)`+`activity()` («долго думает»), `destroy()`.
**События** `react(event)`: `streak`→proud(+затяжка), `combo`→happy, `slow`→bored, `danger`→shock, `sudo`→smug, `root`→nervous,
`night`→bored, `morning`→happy(+глоток), `comeback`→smug, `examPassed`→proud, `theoryOpen`→think.
Помощник `timeEvent(lastVisitMs)` возвращает `night`/`morning`/`comeback` по часам и давности визита.
Фразы — `src/content/palych.ts` (ключи те же).
