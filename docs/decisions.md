# Журнал решений

Формат: что решили → почему. Новые записи — вниз, с датой.

## 2026-10-26 — стартовые решения (бриф)

1. **Платформа: веб-приложение на TypeScript (Vite), ставится на Android как PWA.**
   Один код для телефона и компьютера, не нужны магазины и сборка APK. Полный офлайн не обязателен
   (интернет есть почти везде), но оболочка приложения кэшируется service worker'ом.
2. **Хостинг: GitHub Pages, деплой через GitHub Actions при пуше в `main`.** Бесплатно, без серверов;
   перед сборкой в CI гоняются тесты — сломанный контент не уедет на телефон.
3. **Терминал — симулятор на базе just-bash + своя модель сервера («мир»).** Настоящая VM в браузере тяжёлая
   и медленная на телефоне; just-bash даёт парсер bash, пайпы и текстовые утилиты (~350 КБ gzip, команда
   выполняется за миллисекунды). Поверх — мир: пользователи, группы, владельцы, права; дальше процессы,
   systemd, журнал, сеть, firewalld, SELinux, LVM. Вывод вычисляется из состояния, не захардкожен.
4. **Проверка заданий — по итоговому состоянию мира, а не по строке команды.** Любой корректный путь
   засчитывается (`chgrp`+`chmod g+w`, `chown :dev`+`chmod 775`, `chmod 2775` — всё ок). Если результат
   «почти» (например, `chmod 777` — работает, но дыра), проверка возвращает подсказку.
5. **Поведение и вывод команд — как в актуальном RHEL / Rocky Linux 9.** Нереализованная команда даёт понятное
   сообщение и пишется в локальный журнал, который Артём присылает для доработки.
6. **Точность вывода позже проверяем дифференциальными тестами в CI** (одни и те же команды в контейнере
   Rocky Linux и в симуляторе). Для прототипа не делаем.
7. **Второй этап (не сейчас): режим «Лаборатория»** — траблшутинг на настоящих Rocky VM на ноутбуке Артёма
   через Tailscale, скрипты «сломать / проверить / откатить».

## 2026-10-26 — по итогам разведки just-bash (v3.6.0)

8. **Владельцы и группы храним в своём слое (`World.owners`), а не в ФС just-bash.** В его ФС есть только
   mode; uid/gid нет, права не проверяются, `chown`/`id`/`useradd`/`umask` отсутствуют, `ls -l` у каталогов
   всегда пишет `drwxr-xr-x` (баг). Поэтому `ls`, `stat`, `cat`, `chmod`, `chown`, `chgrp`, `umask`
   и команды пользователей — свои.
9. **Права проверяем в «охраняемой» ФС (Proxy над InMemoryFs) + в своих командах.** Встроенные команды
   just-bash (mkdir, touch, cp, mv, rm, перенаправления) тогда тоже уважают права. Минус: часть встроенных
   команд при отказе пишет «No such file» вместо «Permission denied» (head, grep, rm) — по мере надобности
   заменяем их своими.
10. **cwd и переменные между командами переносит Shell сам** — каждый `bash.exec` в just-bash изолирован.
11. **`node:zlib` в браузерной сборке just-bash заменён заглушкой** (`src/shims/zlib.ts`) — gzip пока не нужен.
12. **Без UI-фреймворка.** Экранов мало, свой `h()` проще и легче; если UI разрастётся — можно взять Preact.
13. **Шрифты локально (fontsource: Nunito + JetBrains Mono)** — без запросов к Google, работают из кэша.
14. **Талисман — Палыч**, мемный старый сисадмин (просьба Артёма). Рисунок — inline SVG, анимации — CSS,
   без картинок и библиотек: лёгкий, чёткий на любом экране, легко добавлять настроения.
15. **`su` без пароля, `sudo` — только для группы wheel.** Интерактивный ввод пароля в прототипе не делали;
   `passwd` поддерживает `--stdin`.
16. **`ls` в колонках и с цветами — только если вывод не идёт в пайп/файл** (эвристика по `|` и `>` в строке),
   ширина колонок — по реальной ширине терминала на экране.

## 2026-10-26 — после теста на телефоне

17. **Реплика Палыча показывается не меньше, чем нужно на чтение** (~15 символов/с + 2 с, минимум 3.5 с),
   повторный тык в это время меняет только мимику. Причина: длинные фразы сменялись раньше, чем их успевали прочитать.
18. **Рабочий процесс с GitHub:** Claude работает в ветке `claude/...`, по команде Артёма создаёт PR и мёржит в `main`;
   пуш в `main` автоматически деплоит на Pages. Память проекта (CLAUDE.md, docs/) должна попадать в `main` —
   новая сессия стартует с него.
