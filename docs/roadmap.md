# Roadmap

## Сделано

### Сессия 1 — 2026-10-26: рабочий прототип
- Разведка just-bash (см. decisions.md, п. 8–11).
- Каркас: Vite + TS, PWA (манифест, иконки с Палычем, service worker), деплой на GitHub Pages через Actions.
- Движок «мир»: пользователи/группы (root, alice в wheel, bob + системные), владельцы, права, umask,
  setgid-наследование, sticky bit, проверка доступа, `/etc/passwd` и `/etc/group` синхронизируются.
- Команды: `ls` (-l -a -A -d -h -R -r -t -S -1, цвета, колонки), `stat` (+ -c), `cat`, `chmod` (числа и буквы,
  -R), `chown`/`chgrp` (-R), `umask` (+ -S), `id`, `whoami`, `groups`, `useradd`, `groupadd`, `usermod`, `userdel`,
  `groupdel`, `passwd --stdin`, `su`/`su -`/`exit`, `sudo` (wheel), `hostname`, `hostnamectl`, `uname`,
  защита от `rm -rf /` и форк-бомбы. Плюс всё из just-bash (cd, mkdir, cp, mv, grep, sed, awk, пайпы...).
- Контент: 2 раздела × 2 урока, 32 задания всех типов (теория, выбор, предскажи вывод, найди ошибку, пропуск,
  плитки, терминал с проверкой состояния).
- UI: главная с деревом уроков, урок (прогресс, плашка результата, повтор ошибок, комбо), финиш с конфетти,
  песочница-терминал, профиль (статистика, звук, журнал неизвестных команд, экспорт/импорт, сброс).
- Терминал для телефона: панель символов, история ↑↓, Tab-дополнение команд и путей, Ctrl+C, ANSI-цвета.
- Геймификация: XP, стрик, цель дня (20 XP), звуки, вибро при ошибке.
- Палыч: 7 настроений, живёт сам (моргает, кофе, сигарета, засыпает), реагирует на ответы и команды.
- Тесты: 35 (поведение команд + «каждое задание терминала решается своим решением»).

- Прототип задеплоен: https://art21414.github.io/linux-trainer/ (PR #1 в main). Артём проверил на телефоне —
  «всё работает круто». Найден 1 баг: реплики Палыча при тыке сменялись за полсекунды → исправлено
  (один таймер скрытия, время показа по длине текста, тык не перебивает недочитанную реплику).

## Известные ограничения прототипа
- Прогресс только на устройстве (экспорт/импорт есть).
- `head`/`grep`/`rm` при отказе в доступе пишут «No such file or directory».
- Порядок stdout/stderr: сначала весь stdout, потом stderr.
- Нет редактора файлов — текст пишем через `echo >`.
