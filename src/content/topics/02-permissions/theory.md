# Права доступа

## Читаем rwx {#rwx}

Первый символ `ls -l` — **тип** (`-` файл, `d` каталог, `l` ссылка). Дальше три тройки: владелец (u), группа (g), остальные (o).

```text
-rw-r-----. 1 alice dev 512 report.txt
 └┬┘└┬┘└┬┘
  u  g  o
```

| Бит | Файл | Каталог |
|---|---|---|
| `r` (4) | читать содержимое | видеть имена (`ls`) |
| `w` (2) | менять содержимое | создавать и удалять файлы внутри |
| `x` (1) | запускать | заходить (`cd`), открывать файлы по имени |

Применяется **только одна** тройка: владельцу — u, даже если у группы прав больше; иначе, если ты в группе, — g; иначе o.

> **Ловушка.** Удалить файл можно без права на сам файл — нужно `w` и `x` на **каталог**. Поэтому `chmod 000 file` от удаления не спасает.

> **На практике.** root обходит проверки `r` и `w`, а `x` — только если он есть хотя бы у кого-то.

## chmod, chown и umask {#chmod}

`chmod g+w f` — буквами (кому `ugoa`, действие `+-=`, что `rwx`). `chmod 640 f` — числами. Для каталогов рекурсия — **`-R`**.

`chown alice:dev f` — владелец и группа; `chown :dev f` или `chgrp dev f` — только группа. Владельца меняет только root.

**umask** вычитает биты из максимума: 666 для файлов, 777 для каталогов.

```bash
$ umask 027
$ touch f; mkdir d
$ stat -c '%a %n' f d
640 f
750 d
```
